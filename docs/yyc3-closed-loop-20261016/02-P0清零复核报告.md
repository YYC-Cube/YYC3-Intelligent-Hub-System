## 3. 残留与风险

### 3.1 P0 残留（唯一）

**P0-4 核心基座未落地** — 需决策后方可推进，属外部依赖缺口而非代码缺陷：

1. `@yyc3/core`（MCP 协议、多 Agent 协作、Skill 沙箱隔离）交付形态未定；

### 3.2 未变的高危项（P1，流入阶段 3）

01 报告 P1-1 ~ P1-10 中，本轮仍可见的项：

- **P1-8 AI 模块双份重复**：`AI/`、`AI高级功能/` 与 `app/services/ai/` 并存，且 `tsconfig.json` 仍 `exclude` 前两者（选择性类型检查）；
- **P1-9 目录双份实现**：`components/ui` 与 `app/components/ui`、`hooks/` 与 `app/hooks/`、`lib/` 与 `app/lib/` 并存；

- **P1-3 卡片缺「编号」字段（复核确认未修）**：`app/marketplace/components/integration-card.tsx` 仅在第 28 行以 `integration.id` 拼接详情链接，未渲染编号文本；且第 86 行仍保留 `integration.id as string` 类型断言；卡片未满足业务要求「编号 + 分类标签 + 方案简介」；
