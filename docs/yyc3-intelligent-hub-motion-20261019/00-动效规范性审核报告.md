# 📊 动效规范性全链路审核报告（五层结构）

> 审核对象：全站页面过渡、组件动效、加载动效、反馈动效
> 审核基准：企业级中后台「克制专业」动效范式 + 项目约束「仅允许 CSS Transition/Transform」
> 本次范围：**只审核与出方案，不改业务代码**；实施清单见 Layer 4。

---

## Layer 1 · 审计总览

### 1.1 基本信息

| 属性 | 值 |
| --- | --- |
| **项目** | YYC³ 集成中心系统（Next.js 16 App Router + React 19 + Tailwind v3 + shadcn/ui + pnpm） |
| **审核范围** | `app/**` 页面与业务组件、`components/ui/**` 基线组件、`app/globals.css`、`tailwind.config.ts`、`app/styles/3d-effects.css` |
| **审核方法** | 动效令牌真源 → 组件源码 → 业务使用点 → 全量参数统计（曲线 / 时长 / 属性）四级取证 |
| **代码基线** | 2026-10-19 工作区当前状态 |
| **约束红线** | 禁止影响性能的复杂动效；所有动效必须基于 CSS Transition / Transform |

### 1.2 审计结论（一句话）

> **动效「有」，但未「成体系」**：存在 1 处阻塞首屏的假加载、25 个文件依赖 JS 动画库、10+ 处无限装饰动画与鼠标追踪，以及 200–800ms 五档时长、4 类缓动、9 种加载指示器并存；与「克制专业 + CSS-only」目标存在系统性偏差。

### 1.3 动效资产盘点（实测）

| 指标 | 实测值 | 判定 |
| --- | --- | --- |
| `framer-motion` 依赖文件 | **25 个**（含首页、市场、收藏、AI 助手、3D 卡片） | 🔴 违反 CSS-only 约束 |
| Framer 动画声明 | **≈80 处** `transition={{...}}` | 🔴 参数分散、不可全局治理 |

## Layer 2 · 问题诊断（按四个核心维度 + 性能红线）

### 2.1 动效规范统一性

#### P0-1 · 全站动效没有「唯一真源」

- 现状：`tailwind.config.ts` 仅定义了 `ease-brand`（且 0 处使用），时长完全依赖 Tailwind 默认值与散落魔法数；Framer 侧另有 6 档时长与 3 套 spring。
- 证据：[tailwind.config.ts](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/tailwind.config.ts#L151-L173)
- 影响：新增页面只能「抄邻近代码」，无法审计、无法统一升级。

#### P1-1 · 同类动效表现不一致

| 同类场景 | 组件 A | 组件 B | 差异 |
| --- | --- | --- | --- |
| 弹层进入 | Dialog `200ms` + zoom 95 | Sheet `500ms` + 侧滑 | 2.5 倍时长差 |
| 弹层退出 | Dialog 默认 | Sheet `300ms` | 退出慢于进入，违反「退出更快」 |
| 弹层遮罩 | Dialog `animate-in/out` 无显式时长 | Sheet 同 | 依赖插件默认值 |
| 列表进场 | 集成列表 `300ms` | 关于页 `500ms` | 节奏不一致 |
| 打字指示 | `assistant-message` 灰点 | `integration-recommendation` 主色点 | 颜色/实现分裂 |
| 页面进入 | Home `PageTransition 800ms` | 其他页无过渡 | 仅首页有，形成割裂 |

- 证据：[dialog.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/components/ui/dialog.tsx#L44)、[sheet.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/components/ui/sheet.tsx#L34)、[toast.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/components/ui/toast.tsx#L28)

#### P2-1 · 曲线命名与语义脱节

- 仅 `ease-brand = cubic-bezier(0.4,0,0.2,1)`，实为 Material Standard，并非品牌专属；进入/退出未区分加速与减速。
- 大量 `ease-in-out`、`ease-linear`、`ease` 混用（侧栏、折叠面板、导航等）。

### 2.2 动效合理性

#### P0-2 · 首屏「假加载」阻塞 2 秒（最高优先级）

```tsx
// page-transition.tsx L33-L46
setInterval(() => { step++; setProgress(Math.min(step * 20, 100)) }, 300) // 5 步 = 1.5s
setTimeout(() => setIsLoading(false), 500) // 再等 0.5s
```

- 位置：[page-transition.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/components/ui/page-transition.tsx#L17-L54)
- 触发面：[app-shell.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/components/layout/app-shell.tsx#L14-L29) + [page.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/page.tsx#L97)（首页 `transition` 开启）
- 影响：每次进入首页强制 2.0s 全屏遮罩；进度是模拟值，误导用户；首屏可交互时间（TTI）人为劣化，违反企业后台效率优先原则。
- 同类：`app/loading/loading.tsx` 把全屏 `LoadingScreen` 用作路由级加载，与骨架屏策略冲突。

#### P0-3 · 无限装饰动效 + 鼠标追踪叠加（性能红线）

首页单页存在：

- 违反约束：既非「克制专业」，也非「CSS Transition/Transform 实现」。

### 2.3 加载动效

#### P0-4 · 三层加载语义未分层

```
L1 全局冷启动  ←→  L2 路由切换  ←→  L3 局部数据
     │                  │                 │
LoadingScreen      骨架屏 / 全屏屏      Spinner / Skeleton
     混乱：/loading 路由用全屏 LoadingScreen，其他路由用 RouteSkeleton；首页另有假加载遮罩
```

| 层级 | 应有形态 | 现状 |
| --- | --- | --- |
| 全局冷启动 | 一次性品牌加载，真实进度或无限指示，≤800ms | `LoadingScreen` 默认模拟 3000ms |
| 路由切换 | 与页面布局 1:1 的 `RouteSkeleton` | 7 处已用骨架；`/loading` 用全屏 |
| 局部数据 | `Skeleton` / `Spinner` / `Button loading` | 9 种实现并存 |

- 证据：[loading-screen.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/components/ui/loading-screen.tsx#L17-L50)、[app/loading/loading.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/loading/loading.tsx#L1-L5)、[global-loading.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/components/ui/global-loading.tsx#L20-L67)

#### P1-3 · LoadingScreen 自身动效过载

[loading-screen.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/components/ui/loading-screen.tsx#L52-L111) 单屏包含 **9 个无限动画**：

- 3 × `animate-float` 光斑（`blur-3xl`，大面积绘制）
- 1 × `animate-float` Logo
- 1 × `animate-ping` + 1 × `animate-pulse` 光环
- 3 × `animate-bounce` 圆点

结论：这是「营销落地页」式加载，不适合企业后台；且与骨架屏策略重复。

### 2.5 性能与可访问性（约束红线）

#### P0-5 · 无全局 `prefers-reduced-motion`

- 全项目 **0 处** `@media (prefers-reduced-motion: reduce)`，**0 处** `motion-reduce:` 工具类；仅轮播做了自动播放判断。
- 受影响：前庭功能障碍用户；低性能设备；系统级「减少动态效果」形同虚设。

#### P0-6 · 滚动进场导致内容默认不可见

- **37 处** `whileInView` + `initial opacity:0`，分布在首页、关于、联系页。
- 证据：[page.tsx L241-L247](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/page.tsx#L241-L247)、[about/page.tsx L39-L41](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/about/page.tsx#L39-L41)、[contact/page.tsx L179-L181](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/contact/page.tsx#L179-L181)
- 风险：静态导出产物中初始样式为 `opacity:0`；JS 加载失败、脚本被阻断或动画库异常时，正文不可见（SEO 抓取与可访问性双风险）。

#### P1-6 · 非合成属性动画清单

| 属性 | 使用点 | 替代 |
| --- | --- | --- |
| `background`（渐变字符串） | 首页 17 处无限动画、`background-pattern.tsx` | 静态渐变 + hover 改 `opacity` |
| `font-size` / `font-weight` | 首页卡片 hover | 仅改 `color` / `transform` |
| `height` | Accordion（可接受，Radix 标准做法） | 保留，限 200ms |

## Layer 3 · 统一方案（全局动效系统）

### 3.1 设计原则（五条铁律）

1. **功能优先**：动效只回答三个问题——「发生了什么 / 从哪里来 / 是否可操作」，不做气氛渲染。
2. **唯一真源**：时长、曲线、距离、缩放全部令牌化，业务只引用令牌，禁止写 `duration-500`。
3. **进入 ≤300ms、退出 ≤进入**：企业后台以效率为先，退出永远更快。
4. **只动 `transform` 与 `opacity`**：颜色/阴影类反馈允许 150ms；禁止无限渐变、无限位移、鼠标追踪。
5. **默认尊重 `prefers-reduced-motion`**：装饰动效直接消失，必要状态指示（Spinner）保留。

### 3.2 动效令牌表（全局唯一真源）

| 令牌 | 值 | 适用 |
| --- | --- | --- |
| `--motion-duration-instant` | `100ms` | 按下、焦点、开关拇指 |
| `--motion-duration-fast` | `150ms` | hover、颜色、Tooltip/Popover/Dropdown 退出 |
| `--motion-duration-base` | `200ms` | Dialog 进入、折叠、页面内容进入、Toast |
| `--motion-duration-slow` | `250ms` | Sheet / Drawer 侧滑进入 |
| `--motion-duration-exit` | `150ms` | 所有退出统一 |
| `--motion-ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 通用位移/颜色 |
| `--motion-ease-enter` | `cubic-bezier(0, 0, 0.2, 1)` | 进入（减速） |
| `--motion-ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 退出（加速） |
| `--motion-ease-emphasized` | `cubic-bezier(0.2, 0, 0, 1)` | Dialog 缩放 |
| `--motion-distance-sm` | `4px` | 页面/轻弹层位移 |
| `--motion-distance-md` | `8px` | Toast / 卡片位移 |
| `--motion-scale-press` | `0.98` | 按下 |
| `--motion-scale-enter` | `0.96` | Dialog / Popover 进入 |
| `--motion-stagger-step` | `30ms` | 列表错峰，上限 5 项 |
