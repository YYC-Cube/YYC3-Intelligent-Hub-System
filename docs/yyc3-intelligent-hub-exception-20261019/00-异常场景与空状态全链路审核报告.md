### 2.2 统一后的三层异常视觉体系（全站唯一真源）

```
┌─────────────────────────────────────────────────────────┐
│  页面级异常  →  StatusPage（全屏四段式，role="alert"）   │
│    not-found    → brand 蓝（找不到≠错误）                │
│    forbidden    → warning 琥珀（待人工介入）             │
│    server-error → destructive 红（服务异常）             │
│    network-error→ warning 琥珀（可自恢复）               │
│    generic      → destructive 红（兜底）                 │
├─────────────────────────────────────────────────────────┤
│  区块级异常  →  ErrorDisplay（Card 容器）                │
│    ErrorBoundary fallback / 局部数据加载失败             │
│    生产环境仅展示通用文案 + 错误编号（digest）           │
├─────────────────────────────────────────────────────────┤
│  数据空态    →  EmptyState（四段式，role="status"）      │
│    size="default" 页面级 / size="sm" 卡片内嵌            │
│    图标容器统一 brand-100 底 + brand-500 图标            │
└─────────────────────────────────────────────────────────┘
```

色彩语义严格遵循 [status-variants.ts](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/lib/yyc3/status-variants.ts) 五态铁律，暗色模式令牌全适配（`dark:bg-amber-950/40` 等）。

## 第五层：补全方案与场景使用规范

### 5.1 标准异常组件代码

核心组件已落库，此处摘录关键 API（完整实现见源文件）：

**StatusPage —— 页面级异常唯一出口**

```tsx
// app/components/error-handling/status-page.tsx
<StatusPage
  variant="not-found"        // not-found | forbidden | server-error | network-error | generic
  code="404"                 // 可选状态码徽章
  onRetry={reset}            // 可选：传入时渲染主「重试」按钮
  errorId={error.digest}     // 可选：生产环境检索锚点
  title={...} description={...} actions={...}  // 可选覆盖默认文案/操作
/>
```

**业务 403 接入范式（API 层）**

```tsx
import { NoPermission } from "@/app/components/error-handling/no-permission"
import { getHttpStatusFromError } from "@/app/services/api-error-handler"

if (getHttpStatusFromError(error) === 403) return <NoPermission />
```

**OfflineBanner**：已在 [AppShell](file:///Users/yanyu/YYC-Cube/YYC3-Intelligent-Hub-System/app/components/layout/app-shell.tsx) 全站挂载，页面禁止重复挂载。

### 5.2 场景使用规范（禁止事项）

1. 页面级异常（404/403/500/网络）**只准用 `StatusPage`**，禁止自绘异常页
2. 数据空态**只准用 `EmptyState`**，禁止 emoji 图标、禁止一行灰字（豁免：h-12 内嵌占位）
3. 区块级异常**只准用 `ErrorDisplay`**（经 ErrorBoundary 挂载）
4. **禁止在生产环境渲染 `error.message` 原文**——统一走 StatusPage/ErrorDisplay 的安全路径
5. 空态图标必须是 lucide 线性图标 + `text-brand-500` + `aria-hidden="true"`
6. 每个空态必须提供至少一个下一步动作（或「数据累积型」场景说明）
7. 异常/空态文案一律走 `errors.*` / 业务命名空间 i18n，中英双份，缺键回退中文
8. 新增异常变体必须同步 `VARIANT_META` 语义色，禁止业务内联取色

### 5.3 i18n 新增文案（中英对齐）

`errors.*`：无权限访问 / 服务暂时不可用 / 网络连接失败 / 当前网络不可用正在尝试重新连接… / 发生了意外错误 / 这是一个意外问题请重试若问题持续请联系我们。/ 浏览集成市场 / 刷新页面 / 错误编号 / 联系管理员 等 13 条；`account.*` 订阅空态引导 3 条。
