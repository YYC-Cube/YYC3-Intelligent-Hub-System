## 第一层：增删改查操作审核

### 1.1 审核结论：整体优秀，1 处危险操作漏斗

| 操作 | 交互模式 | 反馈机制 | 状态 |

| 查询（列表/详情/搜索） | 内存过滤 + 派生渲染 | 结果计数徽章 | ✅ 一致 |

```

## 第三层：搜索与筛选审核

### 3.1 搜索触发方式矩阵（审核后）

| 页面 | 触发方式 | 清除入口 | 记忆恢复 |

| /marketplace/browse | 即时（受控 Input） | 改词即覆盖 | - |

```
[← 上一页] [1] [2] [3] [4] [5] […] [下一页 →]   第 X 页，共 Y 页

## 操作交互规范（全站禁令，后续开发必须遵守）

1. **分页只准用 `ControlledPagination`**，禁止手写页码条；筛选/排序/搜索变更必须 `setCurrentPage(1)`
2. **删除/清空/取消订阅等不可逆操作必须 AlertDialog 二次确认**，文案结构：`确认{操作}？` + 后果描述 + 「此操作无法撤销」
3. 确认弹窗按钮：取消（Cancel 组件）左、确认（Action）右；批量场景标题必须含 `{count}`
4. **所有写操作必须 toast 反馈**（标题 + 描述双段，含影响数量）
5. **空态只准用 `EmptyState`**，禁止 emoji、禁止一行灰字（延续第一阶段规范）
6. 搜索触发分层固定：工作台即时防抖 / 检索页 URL 显式提交 / 个人列表即时，新增页面按场景对号入座
7. 返回导航固定 ArrowLeft + 明确目的地 Link，禁止裸 `router.back()`
8. 批量操作链路：选择模式 → 数量联动按钮 → 确认弹窗 → toast → 自动退出选择模式
