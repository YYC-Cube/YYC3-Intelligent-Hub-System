## 第一层：总体结论

**当前不存在全局页面骨架，31 个页面各自手拼布局。** `app/layout.tsx` 仅承载 Provider 壳（I18n/Theme/Error/Auth/Encryption/Favorites），无任何导航/页脚；全项目仅 `app/admin/layout.tsx` 一个路由级 layout（且只补了 Navbar、缺页脚）。其余 20+ 处页面逐个 `import { Navbar }`、`import { Footer/SiteFooter }` 手动拼装，违反「所有页面必须复用全局布局组件」约束。

### 五维评估

| 维度 | 现状证据 | 评分 |
| --- | --- | --- |
| 时间维（渲染与加载） | 每页重复挂载 Navbar，PageTransition 仅首页用、页间切换无统一过渡 | 55 |
| 空间维（容器与间距） | 双容器体系（`container mx-auto` ×20 处 vs `max-w-page` 令牌仅 2 页）；垂直节奏 `py-8/10/12/16` 四档漂移 | 45 |
| 属性维（结构与语义） | 全项目 page.tsx 中 0 个 `<h1>`（h1 全部散落 client-page/子组件）；`integrations/[id]/client-page.tsx` 用 `div` 代替 `<main>` | 40 |
| 事件维（交互与状态） | `collapsible-navbar.tsx` 的 `isCollapsed` 状态 set 后从未消费（死状态）；导航搜索框是无逻辑 input；账户菜单为手写下拉而非 DropdownMenu；`user-menu.tsx` 零引用死代码 | 50 |
| 关联维（组件依赖） | 双页脚并行（`Footer`×9 文件 / `SiteFooter`×6 页，非迭代关系而是平行双实现）；shadcn `sidebar.tsx` 全套原语零使用；`Breadcrumb` 组件全站仅 1 页使用 | 40 |

**总分 46/100 —— 需整改。** 核心病灶：*骨架责任下沉到了每个页面，导致「同构不同款」*。

## 第三层：标准规范定义（目标态）

项目形态为**营销官网 + iPaaS 工作台混合体**，定义「双壳一体」布局架构：

```
RootLayout（Provider 壳，保持现状）
├── AppShell 〈站点壳〉＝ Navbar + <main id="main"> + SiteFooter
│     └─ 适用：marketplace 系 / about / contact / privacy / terms /
│              developer 系 / account 系 / favorites / login / admin
├── ConsoleShell 〈工作台壳〉＝ Navbar + 左功能栏(可折叠·localStorage 记忆) + 主区
│     └─ 适用：/integrations 列表（现存唯一左栏布局，抽组件化）
└── 布局三件套（所有页面强制复用）
      ├─ PageHeader：面包屑(Breadcrumb) + h1 + 描述 + Actions 槽
      ├─ PageContainer：mx-auto w-full max-w-page px-4 py-8
      └─ SiteFooter：唯一页脚（合并双实现）
```

**布局令牌硬性约定**

| 项 | 唯一值 | 禁止 |
| --- | --- | --- |
| 内容容器 | `mx-auto w-full max-w-page px-4 py-8` | `container mx-auto`、裸 `max-w-4xl/6xl/7xl`、残缺容器 |
| 页头标题 | PageHeader 内置 `text-2xl md:text-3xl font-bold tracking-tight` | 页面自写 text-4xl/5xl 标题（营销 hero 限 about/contact/marketplace 首屏） |
| 面包屑 | components/ui/breadcrumb.tsx，层级=真实路由深度 | 自造 `Link + "/"`、「返回 XX」 |
| 页脚 | SiteFooter（合并版） | Footer、无页脚页面 |
| 语义结构 | 每页恰好一个 `<main>` + 一个 `<h1>` | div 充当 main、CardTitle 充当 h1 |
| 固定层 | z-index 令牌（sticky=1020/modal=1050） | `z-50` 魔法值 |

## 第四层：补全方案（标准布局组件 TSX）

### 4.1 布局三件套

**app/components/layout/page-container.tsx**

```tsx
import { cn } from "@/lib/utils"

/**
 * 唯一内容容器令牌：max-w-page(80rem) + px-4 + py-8。
 * 全项目禁止再出现 container mx-auto / 裸 max-w-4xl 等旁路写法。
 */
export function PageContainer({
  className,
  as: Tag = "div",
  children,
}: {
  className?: string
  as?: "div" | "main" | "section"
  children: React.ReactNode
}) {
  return (
    <Tag className={cn("mx-auto w-full max-w-page px-4 py-8", className)}>
      {children}
    </Tag>
  )
}
```

**app/components/layout/page-header.tsx**

```tsx
"use client"

import {
  Breadcrumb, BreadcrumbItem, BreadcrumbLink, BreadcrumbList,
  BreadcrumbPage, BreadcrumbSeparator,
} from "@/components/ui/breadcrumb"
import { cn } from "@/lib/utils"
import Link from "next/link"
import { Fragment } from "react"

export interface Crumb {
  label: string
  href?: string // 末级或当前页省略 href → 渲染为 BreadcrumbPage
}

/**
 * 标准页头：面包屑 + h1 + 描述 + 操作区。
 * - h1 尺寸全局唯一：text-2xl md:text-3xl font-bold tracking-tight
 * - Actions 槽：主操作放最右第一位，次要操作依次向左
 * - 移动端标题/操作自动折行（flex-col md:flex-row）
 */
export function PageHeader({ crumbs, title, description, actions, className }: {
  crumbs?: Crumb[]
  title: string
  description?: string
  actions?: React.ReactNode
  className?: string
}) {
  return (
    <header className={cn("space-y-3", className)}>
      {crumbs && crumbs.length > 0 && (
        <Breadcrumb>
          <BreadcrumbList>
            {crumbs.map((crumb, i) => {
              const isLast = i === crumbs.length - 1
              return (
                <Fragment key={`${crumb.label}-${i}`}>
                  <BreadcrumbItem>
                    {isLast || !crumb.href ? (
                      <BreadcrumbPage>{crumb.label}</BreadcrumbPage>
                    ) : (
                      <BreadcrumbLink asChild>
                        <Link href={crumb.href}>{crumb.label}</Link>
                      </BreadcrumbLink>
                    )}
                  </BreadcrumbItem>
                  {!isLast && <BreadcrumbSeparator />}
                </Fragment>
              )
            })}
          </BreadcrumbList>
        </Breadcrumb>
      )}
      <div className="flex flex-col gap-3 md:flex-row md:items-end md:justify-between">
        <div className="space-y-1 min-w-0">
          <h1 className="text-2xl md:text-3xl font-bold tracking-tight text-foreground truncate">
            {title}
          </h1>
          {description && (
            <p className="text-sm text-muted-foreground max-w-2xl">{description}</p>
          )}
        </div>
        {actions && (
          <div className="flex flex-wrap items-center gap-2 shrink-0">{actions}</div>
        )}
      </div>
    </header>
  )
}
```

### 4.3 ConsoleShell（工作台壳，integrations 列表专用）

```tsx
"use client"

const STORAGE_KEY = "yyc3.console.collapsed"

export function ConsoleShell({ sidebar, children }: {
  sidebar: (collapsed: boolean) => React.ReactNode
  children: React.ReactNode
}) {
  const [collapsed, setCollapsed] = useState(false)
  // 首帧读取记忆，避免闪烁（SSR 默认展开，水合后同步）
  useEffect(() => {
    setCollapsed(localStorage.getItem(STORAGE_KEY) === "1")
  }, [])
  const toggle = () => {
    setCollapsed((prev) => {
      localStorage.setItem(STORAGE_KEY, prev ? "0" : "1")
      return !prev
    })
  }
  return (
    <div className="flex h-screen flex-col overflow-hidden">
      <Navbar />
      <div className="flex flex-1 overflow-hidden">
        <aside className={cn(
          "hidden lg:flex flex-col border-r border-border bg-card transition-[width] duration-300",
          collapsed ? "w-14" : "w-60",
        )}>
          {sidebar(collapsed)}
          <button type="button" onClick={toggle}
            aria-label={collapsed ? "展开菜单" : "折叠菜单"}
            className="mt-auto flex h-10 items-center justify-center border-t border-border text-muted-foreground hover:text-foreground">
            {collapsed ? "»" : "«"}
          </button>
        </aside>
        <main id="main" className="flex-1 overflow-y-auto">{children}</main>
      </div>
    </div>
  )
}
```

### 4.4 SiteFooter 合并原则

以 site-footer.tsx 为基座升级四栏：第 1 栏品牌+VersionDisplay（吸收自 Footer）；第 2-4 栏产品/支持/法律真链接（吸收自 Footer，`href="#"` 假链接保留 SiteFooter 的非交互 span 决策直至落地页就绪）；动态年份；i18n 统一 use-i18n。

### 4.5 Navbar 三修复

isCollapsed 消费（h-12/h-16 切换）；容器令牌归一（max-w-page）；搜索框接 `/marketplace/search?q=`（决策①：接真功能勿删）。

### 4.6 向导底部栏固定

wizard-navigation 改 `sticky bottom-0 z-sticky bg-background/95 backdrop-blur`。
