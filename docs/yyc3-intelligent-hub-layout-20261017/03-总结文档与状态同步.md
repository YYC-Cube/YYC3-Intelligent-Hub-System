### 已知说明（非缺陷）

1. **integrations 页 SSG 空壳**：`useSearchParams()` 无 Suspense 边界导致静态导出时 CSR bailout——**改造前即存在**（原页面同样使用），浏览器水合后完整（854KB payload）。后续可为该页加 Suspense 边界改善首屏（P2 建议）。
2. marketplace hero/favorites/sync 等页 h1 在 SSG HTML 中为 0：ClientOnly/AuthProvider 条件渲染所致，水合后 h1 存在（设计内行为）。
3. favorites 仅剩 `AlertDialogFooter`（shadcn 弹窗原语，非页脚）。
4. install 页面包屑保留原 4 级 Breadcrumb 结构（i18n 词典自动生成禁止手补新键，保守处理），已补 PageHeader 提供 h1。
