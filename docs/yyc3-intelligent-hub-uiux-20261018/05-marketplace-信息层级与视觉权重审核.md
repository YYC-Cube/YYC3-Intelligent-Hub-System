## Layer 2 · 问题诊断

### 2.1 信息优先级

| # | 问题 | 实测依据 |
| --- | --- | --- |
| P1-1 | 核心内容被前置内容挤出首屏 | Hero 338 + 轮播 336 + 分类 694 = 1368px 前置；桌面首卡 1.80 屏、移动 3.51 屏 |
| P2-1 | 统计区权重高于商品信息 | 3 张卡片、36px `text-primary` 数字，字号为卡片标题（14px）的 2.6 倍 |
| P2-2 | 标签名实不符 | 「精选推荐」渲染 `integrations.slice(0, 8)`（数据集前 8 条），非 `featured` 集合 |

### 2.2 视觉引导

| # | 问题 | 实测依据 |
| --- | --- | --- |
| P0-1 | **轮播白字不可读** | 背景取集成色 50%→25% 冲白 + `text-white`；17/17 调色板色对比度 **1.06–1.51:1**（AA 需 4.5），「立即安装」按钮白底白字完全不可见 |
| P1-2 | 主操作缺失 + 权重倒置 | 卡片内无「安装」CTA；页面最强按钮是 `size="lg"` 实心蓝「浏览更多集成应用」(44px)，指向二级页 |
| P1-3 | Enter 无法搜索 | Hero 搜索框不在 `<form>` 内（`enterForm: false`）——**已于追加轮修复** |

### 2.3 内容密度

| # | 问题 | 实测依据 |
| --- | --- | --- |
| P1-4 | 分类磁贴过载 | 29 个磁贴，桌面 5 行、移动 15 行（1994px）；分类区高于商品区 |
| P2-3 | 卡片内部层级扁平 | 标题 14/600、描述 12、评分 12、chip 12 —— 四层信息仅 2px 差 |
| P2-4 | 长分类名破坏跨语言一致性 | 英文 `Customer Support` 使操作区换行，卡片 199 → 229px |

### 2.4 视觉噪音

| # | 问题 | 实测依据 |
| --- | --- | --- |
| P2-5 | 语义色装饰化 | 分类图标 7 色：`destructive` 用于销售管理/通信工具/社交媒体，`warning` 用于财务/安全/客服 |
| P2-6 | 轮播自动轮转无治理 | 5s 间隔、±1000px 位移、无 hover 暂停、无 `prefers-reduced-motion`（WCAG 2.2.2 风险） |
| P2-7 | 缩放动效噪音 | 卡片 `scale 1.02`、分类 `scale 1.05`，网格内易产生亚像素模糊 |
| P2-8 | 图标按钮无名称 | 15 个纯图标按钮 0 个 `aria-label/title`；轮播圆点仅 8×8px 命中区 |

### 2.5 P0 专项：对比度实测

| 背景色（25% over white） | 白字 | 白字/80 | 结论 |
| --- | --- | --- | --- |
| #FFE01B（黄） | 1.08 | 1.06 | 严重失败 |
| #FFCC22 | 1.12 | 1.09 | 严重失败 |
| #96BF48（绿） | 1.19 | 1.15 | 严重失败 |
| 其余 14 色 | 1.22–1.51 | 1.17–1.39 | 全部 < 4.5:1 |

其他对比度：Hero 副标题 `#DCEBFE` on `#2463EB` = **4.28:1**（20px 常规字重未达 AA）；轮播 `text-white/80` on primary = **3.90:1**。

### 2.6 交互结构缺陷

| # | 问题 | 依据 |
| --- | --- | --- |

## Layer 3 · 优化方案（前后对比）

### 3.1 P0 修复

**轮播对比度**：背景改为品牌深色渐变，集成色降级为图标点缀。

```tsx
// 前：任意集成色冲白 + 白字 → 1.06–1.51:1
<div style={{ backgroundImage: `linear-gradient(to right, ${color}80, ${color}40)` }}>
  <div className="text-white">…</div>

// 后：品牌渐变，白字 5.17:1（primary）/ 6.80:1（accent）
<div className="bg-gradient-to-r from-primary to-accent">
  <div className="text-white">…</div>
```

| 项 | 前 | 后 |
| --- | --- | --- |
| 背景 | 任意集成色 tint | `from-primary to-accent` |
| 次级文字 | `text-white/80` = 3.90:1 | `text-white/95` = 4.82:1 |
| 「立即安装」 | `outline` 白底 + 白字（不可见） | `bg-transparent text-white` + 白/30 边框 |

**嵌套按钮**：链接仅覆盖信息区，操作区独立为兄弟节点。

```
前：<Link><Card>…<button 收藏/>…</Card></Link>
后：<Card><Badge/><button 收藏/><Link><CardContent/></Link></Card>
```

| 项 | 前 | 后（实测） |
| --- | --- | --- |
| 区块顺序 | Hero → 轮播 → 分类 → 商品 | Hero → **商品** → 分类 → 轮播 → 信任条 |
| 首卡位置 · 桌面 | 1616px（1.80 屏） | **507px（0.56 屏）** |
| 首卡位置 · 移动 | 2960px（3.51 屏） | **571px（0.68 屏）** |
| 分类磁贴 | 29（桌面 5 行 / 移动 15 行） | **8（桌面 4×2 / 移动单行横滑）** |
| 分类区高度 · 桌面 | 694px | **304px** |
| 分类区高度 · 移动 | 1994px | **182px（-91%）** |
| 实心主按钮数 | 2 | **1** |
| 卡片安装入口 | 0 | **9**（8 卡 + 轮播） |

### 3.3 P2 治理

| # | 前 | 后 |
| --- | --- | --- |
| 统计区 | 3 卡 / 36px / `4987K+` | 单行信任条 / 14px / **`4.99M+`**（高度 122 → 20px） |
| 精选推荐 | `slice(0, 8)` | `featured` 集合前 8 条 |
| 分类图标 | 7 种语义色 | **1 种中性色** + hover 主色 |
| 轮播轮转 | 5s、无暂停 | **8s + hover/focus 暂停 + reduced-motion 停用** |
| 图标按钮命名 | 10 个无名称 | **0 个**（收藏/通知/菜单/箭头/圆点） |
| Hero 副标题 | 4.28:1 | **4.82:1**（`text-white/95`） |
| 悬停动效 | 卡片 1.02 / 分类 1.05 缩放 | 去缩放，改描边 + 阴影 |

### 3.4 排版方案决策（不做自适应算法）

| 方案 | 一致性 | 可预测性 | 成本 | 结论 |
| --- | --- | --- | --- | --- |
| **语义令牌（固定刻度）** | ★★★★★ | ★★★★★ | 低 | **采用** |
| 断点双档 | ★★★★ | ★★★★★ | 中 | 实测无需 |
| 容器查询流体字号 | ★★★ | ★★ | 中高 | 不采用 |
| JS 测量自适应 | ★★ | ★ | 高 | 否决 |

**决策依据**：网格内同行卡片宽度恒等，自适应无区分收益；流体字号产生分数像素、破坏垂直节奏，并放大 CJK/拉丁折行差异；JS 测量存在 SSR/CSR 字号跳变与布局抖动。

**落地令牌**：`card-title 15/22/600`、`card-body 13/18`、`card-meta 12/16`、`card-chip 11/16`。

**影响实测**：卡片高度 195 → 199px（+2%）；218px 窄卡无溢出；英文长分类名经 chip 截断后高度稳定在 199px。

## Layer 4 · 使用规范（接入四律）

1. **语义色禁装饰**：`destructive / warning / success / info` 仅表达状态；分类、标签、图标统一用 `primary / muted / foreground`。
2. **主 CTA 唯一**：单屏最多 1 个实心 `default` 按钮，其余动作用 `outline / ghost / link`。
3. **核心内容不得后置**：首屏必须露出 ≥1 行商品卡；装饰性模块（轮播/统计）不得占据首屏主体。
4. **任意色底必测对比度**：动态色背景 + 白字必须 ≥4.5:1（大字 ≥3:1），禁止直接用数据色做背景层。
5. **卡片排版只用令牌**：新增卡片型组件引用 `text-card-*`，禁止再用同值 `text-sm/text-xs` 表达不同语义。
