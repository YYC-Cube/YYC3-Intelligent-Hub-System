项目存在**双组件层**：

```
components/ui/        ← shadcn 基线层（真源，含设计令牌绑定）
```

### 3.1 基线按钮 `components/ui/button.tsx`（全量重写·全站唯一真源）

```tsx
import { Slot } from "@radix-ui/react-slot"
import { cva, type VariantProps } from "class-variance-authority"
import { Loader2 } from "lucide-react"
import * as React from "react"

import { cn } from "@/lib/utils"

/**
 * YYC³ 基线按钮 —— 全站唯一按钮真源。
 *
 * 五种基础类型：default（主要）/ secondary（次要）/ dashed（虚线）/ ghost·link（文字）/ destructive（危险）
 * 语义功能色：success / warning / info / accent（对应 globals.css 功能色令牌）
 * 禁用策略：disabled:pointer-events-none（asChild 链接场景同样阻断交互）；
 * 输入型组件（Input/Textarea/Select）统一采用 disabled:cursor-not-allowed，两类策略由组件类别定义，不混用。
 */
const buttonVariants = cva(
  "inline-flex items-center justify-center gap-2 whitespace-nowrap rounded-md text-sm font-medium ring-offset-background transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:pointer-events-none disabled:opacity-50 [&_svg]:pointer-events-none [&_svg]:size-4 [&_svg]:shrink-0",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground hover:bg-primary/90",
        secondary: "bg-secondary text-secondary-foreground hover:bg-secondary/80",
        outline:
          "border border-input bg-background hover:bg-accent hover:text-accent-foreground",
        dashed:
          "border border-dashed border-input bg-background hover:bg-accent hover:text-accent-foreground",
        ghost: "hover:bg-accent hover:text-accent-foreground",
        link: "text-primary underline-offset-4 hover:underline",
        destructive:
          "bg-destructive text-destructive-foreground hover:bg-destructive/90 focus-visible:ring-destructive",
        success:
          "bg-success text-success-foreground hover:bg-success/90 focus-visible:ring-success",
        warning:
          "bg-warning text-warning-foreground hover:bg-warning/90 focus-visible:ring-warning",
        info: "bg-info text-info-foreground hover:bg-info/90 focus-visible:ring-info",
        accent: "bg-accent text-accent-foreground hover:bg-accent/90",
      },
      size: {
        xs: "h-7 rounded-sm px-2 text-xs",
        sm: "h-9 rounded-md px-3",
        default: "h-10 px-4 py-2",
        lg: "h-11 rounded-md px-8",
        icon: "h-10 w-10",
        "icon-sm": "h-9 w-9",
      },
      rounded: {
        default: "",
        full: "rounded-full",
        none: "rounded-none",
      },
      width: {
        default: "",
        full: "w-full",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "default",
      rounded: "default",
      width: "default",
    },
  }
)

export interface ButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement>,
  VariantProps<typeof buttonVariants> {
  asChild?: boolean
  /** 加载态：自动禁用（disabled + aria-busy）并内联旋转指示器，替代业务各自实现 loading */
  loading?: boolean
}

const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  (
    {
      className,
      variant,
      size,
      rounded,
      width,
      asChild = false,
      loading = false,
      disabled,
      children,
      ...props
    },
    ref
  ) => {
    const classes = cn(
      buttonVariants({ variant, size, rounded, width, className })
    )

    if (asChild) {
      return (
        <Slot className={classes} ref={ref} {...props}>
          {children}
        </Slot>
      )
    }

    return (
      <button
        ref={ref}
        className={classes}
        disabled={disabled || loading}
        aria-busy={loading || undefined}
        {...props}
      >
        {loading ? (
          <>
            <Loader2 className="animate-spin" aria-hidden="true" />
            {children}
          </>
        ) : (
          children
        )}
      </button>
    )
  }
)
Button.displayName = "Button"

export { Button, buttonVariants }
```

**要点**：① 五种基础类型齐备（default/secondary/dashed/ghost·link/destructive）；② `loading` 自动级联 `disabled` 并声明 `aria-busy`；③ 语义功能色变体各带同色 focus 环；④ `rounded`/`width` 修饰符兼容 YanyuButton 旧 API。

### 3.4 可关闭标签页 `app/components/ui/custom-tabs.tsx`（重写·修复 P0-3 + 完整键盘导航）

```tsx
"use client"

import { X } from "lucide-react"
import * as React from "react"

import { useI18n } from "@/app/hooks/use-i18n"
import { cn } from "@/lib/utils"

// 定义标签项的类型
interface TabItem {
  id: string
  title: string
  content: React.ReactNode
  icon?: React.ReactNode
}

interface CustomTabsProps {
  tabs: TabItem[]
  defaultValue?: string
  onTabClose?: (id: string) => void
  onTabChange?: (id: string) => void
  className?: string
}

/**
 * 可关闭型标签页（浏览器标签心智）—— 补齐标准 Tabs 缺失的关闭能力。
 * 无障碍规范：tablist/tab/tabpanel 完整角色 + aria-selected + 方向键/Home/End 导航（roving tabindex）；
 * 关闭按钮与标签按钮为同级兄弟节点（HTML 禁止 button 嵌套 button）。
 */
const CustomTabs: React.FC<CustomTabsProps> = ({
  tabs,
  defaultValue,
  onTabClose,
  onTabChange,
  className,
}) => {
  const { t } = useI18n()
  const [activeTab, setActiveTab] = React.useState(
    () => defaultValue ?? tabs[0]?.id
  )
  const tabListRef = React.useRef<HTMLDivElement>(null)

  const focusTab = (id: string) => {
    const btn = tabListRef.current?.querySelector<HTMLButtonElement>(
      `[role="tab"][data-tab-id="${id}"]`
    )
    btn?.focus()
  }

  const moveFocus = (id: string, offset: number) => {
    const index = tabs.findIndex((tab) => tab.id === id)
    if (index === -1) return
    const next = tabs[(index + offset + tabs.length) % tabs.length]
    focusTab(next.id)
  }

  // 处理标签变化
  const handleTabChange = (id: string) => {
    setActiveTab(id)
    onTabChange?.(id)
  }

  // 处理标签关闭
  const handleTabClose = (id: string, e: React.MouseEvent) => {
    e.stopPropagation()

    onTabClose?.(id)

    // 如果关闭的是当前激活的标签，自动选中左侧相邻标签
    if (id === activeTab && tabs.length > 1) {
      const currentIndex = tabs.findIndex((tab) => tab.id === id)
      const newIndex = Math.max(0, currentIndex - 1)
      const newActiveTab = tabs[newIndex].id
      setActiveTab(newActiveTab)
      onTabChange?.(newActiveTab)
    }
  }

  // 键盘导航（WAI-ARIA Tabs Pattern）
  const handleKeyDown = (id: string, e: React.KeyboardEvent) => {
    switch (e.key) {
      case "ArrowRight":
        e.preventDefault()
        moveFocus(id, 1)
        break
      case "ArrowLeft":
        e.preventDefault()
        moveFocus(id, -1)
        break
      case "Home":
        e.preventDefault()
        if (tabs[0]) focusTab(tabs[0].id)
        break
      case "End":
        e.preventDefault()
        if (tabs[tabs.length - 1]) focusTab(tabs[tabs.length - 1].id)
        break
      case "Enter":
      case " ":
        e.preventDefault()
        handleTabChange(id)
        break
    }
  }

  // 确保有标签数据
  if (tabs.length === 0) {
    return (
      <div className="flex h-12 w-full items-center justify-center text-muted-foreground">
        {t("ui.暂无标签")}
      </div>
    )
  }

  return (
    <div className={cn("w-full", className)}>
      {/* 横向滚动的标签列表 */}
      <div
        ref={tabListRef}
        role="tablist"
        aria-label={t("ui.标签页")}
        className="flex h-12 items-center overflow-x-auto whitespace-nowrap px-4 [scrollbar-width:none] [&::-webkit-scrollbar]:hidden"
      >
        {tabs.map((tab) => {
          const isActive = activeTab === tab.id
          return (
            <div key={tab.id} role="presentation" className="relative flex items-center">
              <button
                type="button"
                role="tab"
                data-tab-id={tab.id}
                aria-selected={isActive}
                aria-controls={`custom-tab-panel-${tab.id}`}
                id={`custom-tab-${tab.id}`}
                tabIndex={isActive ? 0 : -1}
                onClick={() => handleTabChange(tab.id)}
                onKeyDown={(e) => handleKeyDown(tab.id, e)}
                className={cn(
                  "flex h-9 items-center rounded-sm px-3 py-2 pr-9 text-sm font-medium transition-all",
                  isActive
                    ? "border-2 border-primary bg-card text-foreground"
                    : "border border-border bg-muted text-muted-foreground hover:text-foreground"
                )}
              >
                {/* 主题 logo */}
                <span className="mr-2 flex h-5 w-5 items-center justify-center">
                  {tab.icon || (
                    <span className="flex h-full w-full items-center justify-center rounded-full bg-primary text-xs text-primary-foreground">
                      {tab.title.charAt(0)}
                    </span>
                  )}
                </span>

                {/* 标题文字 */}
                <span>{tab.title}</span>
              </button>

              {/* 关闭按钮（兄弟节点，禁止嵌套 button） */}
              {onTabClose && (
                <button
                  type="button"
                  aria-label={t("ui.关闭 {title} 标签", { title: tab.title })}
                  onClick={(e) => handleTabClose(tab.id, e)}
                  className="absolute right-1.5 flex h-4 w-4 items-center justify-center rounded-full text-muted-foreground transition-colors hover:bg-muted hover:text-foreground focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring"
                >
                  <X size={12} aria-hidden="true" />
                </button>
              )}
            </div>
          )
        })}
      </div>

      {/* 标签内容区域：面板保持挂载（仅 hidden 切换），保留面板内表单状态 */}
      <div className="mt-2">
        {tabs.map((tab) => (
          <div
            key={tab.id}
            role="tabpanel"
            id={`custom-tab-panel-${tab.id}`}
            aria-labelledby={`custom-tab-${tab.id}`}
            hidden={activeTab !== tab.id}
          >
            {tab.content}
          </div>
        ))}
      </div>
    </div>
  )
}

CustomTabs.displayName = "CustomTabs"

export { CustomTabs }
```

### 3.5 业务分页 `app/integrations/components/Pagination.tsx`（重写·复用基线骨架）

```tsx
"use client"

import { ChevronLeft, ChevronRight } from "lucide-react"

import { useI18n } from "@/app/hooks/use-i18n"
import { buildPageWindow } from "@/app/utils/pagination"
import { Button, buttonVariants } from "@/components/ui/button"
import {
  Pagination as PaginationRoot,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
} from "@/components/ui/pagination"
import { cn } from "@/lib/utils"

type PaginationProps = {
  currentPage: number
  totalPages: number
  onPageChange: (page: number) => void
  /** 页码窗口内展示的页码数量，默认 5 */
  windowSize?: number
  className?: string
}

/**
 * 集成列表受控分页 —— 组合基线 Pagination 骨架 + buildPageWindow 窗口工具，
 * 禁止在业务内重复实现分页通用能力。
 */
export default function Pagination({
  currentPage,
  totalPages,
  onPageChange,
  windowSize = 5,
  className,
}: PaginationProps) {
  const { t } = useI18n()

  const safeCurrent = Math.min(Math.max(1, currentPage), Math.max(1, totalPages))
  const pages = buildPageWindow(safeCurrent, totalPages, windowSize)
  const showStartEllipsis = pages.length > 0 && pages[0] > 1
  const showEndEllipsis =
    pages.length > 0 && pages[pages.length - 1] < totalPages

  return (
    <PaginationRoot className={className}>
      <PaginationContent>
        <PaginationItem>
          <Button
            variant="outline"
            size="icon"
            aria-label={t("ui.上一页")}
            onClick={() => onPageChange(safeCurrent - 1)}
            disabled={safeCurrent <= 1}
          >
            <ChevronLeft className="h-4 w-4" />
          </Button>
        </PaginationItem>

        {showStartEllipsis && (
          <PaginationItem>
            <PaginationEllipsis />
          </PaginationItem>
        )}

        {pages.map((page) => (
          <PaginationItem key={page}>
            <button
              type="button"
              aria-label={t("ui.第 {page} 页", { page: String(page) })}
              aria-current={page === safeCurrent ? "page" : undefined}
              disabled={page === safeCurrent}
              onClick={() => onPageChange(page)}
              className={cn(
                buttonVariants({
                  variant: page === safeCurrent ? "outline" : "ghost",
                  size: "icon",
                })
              )}
            >
              {page}
            </button>
          </PaginationItem>
        ))}

        {showEndEllipsis && (
          <PaginationItem>
            <PaginationEllipsis />
          </PaginationItem>
        )}

        <PaginationItem>
          <Button
            variant="outline"
            size="icon"
            aria-label={t("ui.下一页")}
            onClick={() => onPageChange(safeCurrent + 1)}
            disabled={safeCurrent >= totalPages}

          </Button>
        </PaginationItem>

        <PaginationItem aria-live="polite">
          <span className="text-sm text-muted-foreground px-2 whitespace-nowrap">
            {t("integrations.第 {current} 页，共 {total} 页", {
              current: String(safeCurrent),

            })}
```

## Layer 5 · 规范沉淀与后续建议

### 5.1 本次确立的全站规范（约束力：硬性）

1. **单一真源**：基线组件（`components/ui/`）是变体/尺寸/状态唯一定义处；定制层只允许「门面兼容」与「能力扩展」，禁止另起炉灶。
2. **禁用策略二分法**：操作型组件（Button/Tabs/链接）= `disabled:pointer-events-none`；输入型组件（Input/Textarea/Select）= `disabled:cursor-not-allowed`。由组件类别定义，禁止混用。
3. **z-index 一令牌一位**：backdrop(1040) / modal(1050) / popover(1060) / tooltip(1070) / toast(1080)，禁止 `z-[100]` 魔法值。
4. **非交互元素零 hover**：Badge/Tag 类纯展示元素不设 hover 反馈。
5. **色值纪律**：业务页面禁止 Tailwind 调色板硬编码色（`bg-blue-600` 等），一律语义色（success/warning/info/destructive/accent）或品牌色阶（brand-50~950）；文案色必须 bg 与 `text-*-foreground` 成对出现。
6. **i18n 键规范**：`<namespace>.<中文原文>`；zh-CN 与 en 键序一一对应；新增键必须双语言同步提交。
