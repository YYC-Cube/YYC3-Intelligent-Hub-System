## Layer 2 · 方案设计

### 2.1 P2-1 数据源合并架构

```
app/data/learning-paths.ts（新建·唯一数据源）
├── LearningPath / Module / Step 类型
├── learningPaths（15 模块完整结构，自 page.tsx 迁移）
├── findModuleById(id) → { module, path, prevModule, nextModule }
└── getAllModuleIds() → generateStaticParams / sitemap 共用

app/data/learning-content.ts（新建·正文层，与结构分离）
└── learningContent: Record<stepId, markdown>（component-basics 3 步已收录）

消费方（全部同源，禁止副本）：
├── progressive-guide/page.tsx（列表页，删除本地 280 行数据）
├── module/[id]/page.tsx（generateStaticParams + generateMetadata）
└── module/[id]/client-page.tsx（真实模块渲染 + 正文缺失占位）
```

**结构/正文分层决策**：15 个模块的结构数据（标题/描述/步骤）全量就绪；正文 markdown 按模块逐步补齐（当前收录 3 步）。未收录步骤渲染「内容建设中」占位——结构与导航真实、正文透明降级，避免为凑数伪造教学内容。

### 2.2 P2-2 规则设计（两个迭代收敛误报）

初版 selector 全局拦 `Property[title]` 含品牌词 → 误伤 toast 文案与合法页面名「集成中心」。最终收敛为**双上下文 + 后缀形态**：

1. **client 页禁导出 metadata**（自定义 local 规则，AST 判定 `"use client"` directive）：
   - `VariableDeclarator[name='metadata']` / `generateMetadata`（const 与 function 两种形态）/ `ExportSpecifier` re-export
2. **title 自拼后缀**（no-restricted-syntax，限 metadata 赋值上下文）：
   - `VariableDeclarator[id.name='metadata'] Property[title][value.raw=/[-–—|]\s*(言语云|集成中心|YanYu|YYC)/]`
   - `CallExpression[callee.name='createMetadata'] Property[title][...]`
   - 页面名本身含品牌词（如「集成中心」）不受影响；根 layout 的 template 为 TemplateLiteral 天然豁免

### 2.3 P3-1 校验模型（静态导出下的服务层防线）

```
路由防线（防误入）          数据防线（防越权写盘）           ← 本轮新增
RequireAuth（layout）  →  requireSession(resource, expectedUserId)
  │ 不信任调用方 React 状态，直接核对持久会话真源 localStorage("user")
  └── 校验链：会话存在（UnauthorizedError）→ 归属一致（SessionMismatchError）
```

接入点（敏感数据写入口）：`app/services/encryption.ts` 的 `saveUserEncryptionSettings` / `saveKeyPackage`；`subscription-context` 唯一写盘口 `saveSubscriptions`。

### 2.4 P3-2 收录策略

公开内容页收录（静态 18 路径 + 动态展开：29 集成 ×2 入口 + 28 分类 + 15 模块 ≈ 120 URL）；登录墙/内部页排除（/admin、/account、/favorites、/login、/error-test、/loading*、/examples、/design-system）。URL 带尾斜杠与 next.config trailingSlash 一致；分类中文参数与 generateStaticParams 同规则 encodeURIComponent。

```typescript
import { findModuleById, getAllModuleIds } from "@/app/data/learning-paths"

/** 由共享数据源（learning-paths）驱动生成全部学习模块的静态路径。 */
export function generateStaticParams() {
  return getAllModuleIds().map((id) => ({ id }))
}

export async function generateMetadata({
  params,
}: {
  params: Promise<{ id: string }>
}): Promise<Metadata> {
  const { id } = await params
  const lookup = findModuleById(id)
  if (!lookup) return {}

  return createDynamicMetadata({
    title: lookup.module.title,
    description: `${lookup.module.description}（${lookup.path.title}路径 · ${lookup.module.duration} 分钟）`,
    path: `/developer/progressive-guide/module/${id}/`,
  })
}
```

### 3.3 数据层会话校验（lib/yyc3/session.ts 核心签名）

```typescript
export function requireSession(resource: string, expectedUserId?: string): StoredSession {
  const session = getStoredSession()
  if (!session) throw new UnauthorizedError(resource)
  if (expectedUserId !== undefined && session.id !== expectedUserId) {
    throw new SessionMismatchError(resource, expectedUserId)
  }
  return session
}

// 服务层写入口接入范式（app/services/encryption.ts）
export function saveKeyPackage(userId: string, keyPackage: KeyPackage): void {
  requireSession("key_package", userId)
  localStorage.setItem(`key_package_${userId}`, JSON.stringify(keyPackage))
}
```

### 3.5 sitemap 数据源驱动（app/sitemap.ts 核心）

```typescript
export default function sitemap(): MetadataRoute.Sitemap {
  const url = (path: string) => `${SITE_URL}${path}/`
  return [
    ...staticPaths.map((path) => ({ url: url(path), lastModified })),
    ...[
      ...integrations.flatMap((i) => [url(`/integrations/${i.id}`), url(`/marketplace/integration/${i.id}`)]),
      ...categories.filter((c) => c !== "全部分类").map((c) => url(`/marketplace/category/${encodeURIComponent(c)}`)),
      ...getAllModuleIds().map((id) => url(`/developer/progressive-guide/module/${id}`)),
    ].map((u) => ({ url: u, lastModified })),
  ]
}
```

## Layer 5 · 规范沉淀与后续建议

### 5.1 固化规范（约束力：硬性）

1. **数据源唯一真源**：路由参数（generateStaticParams）、元数据（generateMetadata）、页面渲染（client）、站点地图（sitemap）必须消费同一数据文件，禁止任何形式的硬编码副本。
2. **结构/正文分层**：结构数据（标题/步骤/时长）与正文内容（markdown）分文件管理；正文未收录时必须「透明降级占位」，禁止伪造内容。
3. **数据写盘三查**：受保护数据写入口必须 `requireSession(resource, expectedUserId)`——会话存在 + 归属一致，不信任 React 状态。
4. **lint 防回潮先于回潮**：新增架构约束时同步落地 lint 规则；selector 必须**上下文限定 + 形态精确**，上线前用存量代码验证误报为零。
